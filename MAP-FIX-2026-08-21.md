# MobileGL PZ — fix Creator Map și World Map

Data: 2026-08-21  
Țintă: Android ARM64, Project Zomboid, `MOBILEPZ_V1_CANDIDATE=ON`

## Simptom reparat

- Create New World / Select Spawn Location: panoul mapei complet bej;
- World Map din joc: fundal și etichete de oraș vizibile, dar fără tile-urile și
  geometria texturată a mapei;
- PZF16 global readucea conținutul, dar afecta UI-ul și randarea lumii.

## Implementare

`UIWorldMap` este identificat numai prin starea sa reală de randare: stencil
activ cu `GL_EQUAL`, referință 1, și depth oprit. În acea fereastră, conversia
este permisă numai programelor cu interfața `VBORenderer` (`aPosition`, `aColor`,
`ModelViewProjection`, `userDepth`).

Pentru un apel `GL_QUADS` cu 4×N vârfuri/indici, frontendul emite N apeluri
`GL_TRIANGLE_FAN`, fiecare cu exact patru vârfuri. Astfel, un lot cu mai multe
quad-uri nu este tratat greșit ca un singur fan. Sunt acoperite toate cele trei
intrări folosite de LWJGL: Arrays, Elements și RangeElements.

Identitatea exactă a shaderului MAP SDF rămâne ca rută separată. Nu există
override de MVP, mutație de stencil/depth, logger per-draw sau conversie globală.
